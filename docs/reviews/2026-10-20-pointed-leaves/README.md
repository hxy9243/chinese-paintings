# Pointed foliage correction

Replaced faceted leaf pellets with tapered, folded leaf blades. The featured old trees now have sparse needle-like fans, and younger trees use broader pointed leaves. Trunks and branch gaps remain visible. Distant geometry retains the same pointed silhouette with fewer blades.
